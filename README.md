
# Gestão Social Ciclo — Instituto Natura Local

## Sobre o projeto

O Gestão Social Ciclo é um MVP desenvolvido para apoiar o acompanhamento e o registro de adesões às iniciativas sociais, facilitando a organização das informações.

## Objetivo

Desenvolver uma solução simples e acessível para registrar e consultar a participação nas iniciativas sociais.

## Iniciativas acompanhadas

- Crer Para Ver
- Avon Por Elas

## Funcionalidades

- Página inicial de apresentação.
- Cadastro de adesões.
- Registro do nome da consultora.
- Seleção da iniciativa social.
- Registro do ciclo, data e situação.
- Consulta das adesões cadastradas.
- Armazenamento de dados em banco SQLite.
- Menu de navegação entre as telas.

## Tecnologias utilizadas

- Python
- Flask
- HTML5
- CSS3
- SQLite
- Git e GitHub

## Acessibilidade

O projeto utiliza recursos para facilitar a navegação, incluindo:

- Identificação dos campos por rótulos.
- Navegação por links.
- Estrutura semântica HTML.
- Indicação visual de foco no menu.
- Áreas de interação com tamanho adequado.

## Como executar o projeto

1. Instale o Python.
2. Instale o Flask:

   pip install flask

3. Abra o terminal na pasta do projeto.
4. Execute:

   python app.py

5. Acesse no navegador:

   http://127.0.0.1:5000

## Banco de dados

O projeto utiliza SQLite para armazenar os registros de adesões localmente.

O banco de dados é criado automaticamente na primeira execução.
